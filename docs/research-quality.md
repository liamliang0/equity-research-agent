# 当前研究交付的质量与边界

当前完成一个 AVGO 条件研究案例：原披露核对、可比期间现金流衔接、显式模型假设、价格反推与后续观察条件。它是可检查的个人研究实践，不是完整机构覆盖或精确目标价。其他证券的数据概览不能称为完成研究。

## 已补上的关键环节

- 回答“AI 业务兑现与当前价格要求是否一致”，将证据、解释和假设分开。
- SEC 原始数据按相同财年截止日构造 TTM；季度现金流以累计差额复算，并与官方业绩公告的四舍五入数字核对。
- 桥接经营现金流、资本支出、股权薪酬与现金利息，保留标签、单位、期间和出处。价格、股数、净债务和利率分别记录时点。
- 运行五年现金流情景、逆向增长和 WACC×永续增长敏感性；同时展示最近季度年化的起点敏感性，避免仅用落后 TTM 下结论。
- 三个章节区分研究阅读、交互式计算和证据核查。已安装并应用 [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)，设计记录在 report-design.md。

## 仍然不能声称什么

1. 模型使用 FCFF 代理，未完成租赁、少数股东等全部调整。SBC 作为经济成本扣除，固定股数，不另叠加未来稀释。
2. 正常化税率、ERP、Beta 和未来增长为分析假设，不是市场一致预期。终值占比高，必须看敏感性。
3. 单季年化可能夸大持续性，TTM 可能滞后快速增长；两个起点都不是无条件正确。
4. HTTP 成功不保证有可解析财务字段，原文片段匹配也不等于全面审计。缺项不得填零或伪装中性。
5. 本次完整叙述通过交互式 Codex 研究和人工式原披露核对形成，没有把失败的 CLI 尝试标成新自动运行成功。刷新数据和模型不代表刷新了 AI 解释。
6. 尚未完成同业估值、全面分部预测及所有观察对象研究，不能仅凭此报告做确定性买卖判断。
