# 报告改版设计

受众：招聘者优先。GitHub首屏先解释项目成果、作者贡献与验证入口；一次点击进入交互式报告。公开页默认展示作品导览，研究细节按公司展开。

## 视觉方案

用清晰的证券研究工作台，而不是同尺寸卡片墙。左侧是证券目录，右侧围绕一个问题给结论和证据；估值页以情景范围、当前价位置和参数编辑为主。信息左对齐。

颜色：纸面白`#F7FAFF`、正文深蓝`#102745`、强调蓝`#3154D9`、证据青`#137C75`、风险陶红`#B85C40`、分隔线`#DCE4F0`。不依靠渐变、绿色行情墙或装饰阴影。

字体：Bahnschrift用于拉丁标题和数字，微软雅黑用于中文正文；系统回退保证本地离线可读。数字采用等宽宽度，但不使用全大写眉题。

```text
证券目录 | 研究问题 + 有条件的结论
         | 研究结论 / 价格与假设 / 来源与过程
         | 三条关键证据 + 最大分歧
         | 现金流桥接 / 情景区间 / 参数敏感性
```

## 反模板检查

移除11组相同六卡片作为默认主界面的方案：视角名称不是用户需要优先阅读的信息。让“未来现金流需要增长多少才支持价格”的情景图成为主要视觉元素，其余区域保持克制。宏观、来源、AI流程不再与研究结论争夺首屏。

## 实现和验收

单文件HTML，无CDN、无跟踪、无前端构建依赖。明确区分已报告数据、算式推导、情景假设、研究解释；不将预设假设伪装成用户观点或机构一致预期。

检查桌面/手机、证券切换、标签切换、情景参数修改、来源展开、HTML转义、键盘焦点和无脚本降级内容。公开目录覆盖10家公司的研究。逐一验证切换、模型重算、来源查看和下载。

应用已审阅的[Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)设计原则。它提供排版与信息设计指导，不负责证券分析结论。
